Rename the default enrolled-host identity filename and sshd metadata key consistently to realm, and update affected documentation and tests. Agree on handling existing enrolled-host files and fragments before implementation; preserve the stored realm value so the cleanup does not change authorization identities. Do not introduce compatibility aliases or automatic migration behavior without an agreed requirement.

Done when enrolled-host paths and metadata use realm consistently and the agreed handling of existing enrollments is documented and validated. Target: before 1.0.
