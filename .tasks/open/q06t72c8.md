Detect when a hostname matches multiple inventory patterns and log a warning that identifies the hostname and conflicting patterns so administrators can resolve the ambiguity.

Exact-name matches continue to take precedence over patterns. Preserve the existing ambiguity error when lookup falls back to patterns and finds multiple matches; this task adds diagnostic visibility, not a winner-selection rule.

Keep detection within the storage/provider lookup strategy rather than requiring an exhaustive scan of all hosts. The agreed domain direction is one Host type; storage owns the separation and indexing of exact names and patterns.

Deferred follow-up to the inventory model cleanup. Do not implement as part of the current refactor.
