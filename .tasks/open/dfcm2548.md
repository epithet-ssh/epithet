## Problem

The public control API uses a bespoke JSON RPC envelope: facts.ControlRequest
contains an action discriminator and fields for unrelated operations, while
ControlResponse contains optional action-specific results. Server.execute
switches on the action. Enrollment even repeats its operation and resource ID
in the body although POST /manage/HOST_ID already identifies them.

The user explicitly requested replacing this pattern. ADR 0002 retained the
CLI/control envelope while making the provider protocol resource-oriented;
update that decision as part of this work.

## Requested change

Replace the public control action envelope with resource-oriented HTTP endpoints.
Use methods, paths, query parameters, and HTTP preconditions to express operations
where appropriate, with request and response bodies specific to their resources.
Remove redundant action/ID fields and the generic response union. Define the
concrete endpoint mapping during this task; do not merely move action names into
another RPC wrapper.

Cover the existing enrollment, host creation/list/read/edit/removal, token
issuance, and inventory/directory audit operations. Update AdminClient and affected
CLI, agent/broker callers, tests, discovery, and documentation together.

Preserve existing public authorization, credential separation, client-generated
host IDs, enrollment retry/conflict semantics, optional provider versioning,
pagination, and provider ownership. Keep authentication and shared HTTP handling
coherent without introducing a general RPC or routing framework. Decide any
compatibility need explicitly rather than retaining a second protocol by default.

## Scope and validation

Deferred from [f1ljvrhn](../closed/f1ljvrhn.md); no implementation in the current
enrollment change. This concerns the public control HTTP contract, not a redesign
of SSH agent transport or provider storage.

Related: [n4pge2o8](n4pge2o8.md) separately splits the private inventory provider's
HTTP switch into logical handlers; that task preserves its API. The
[SCIM signed-token task](ldh8oxeq.md) remains separate.

Validate the affected CLI-to-control and control-to-provider paths, including
authorization failures, conditional edits, enrollment retries, and audit/list
pagination. Run make build and make test; run broker race tests if its paths change.
