Add an explicit privileged one-shot host enrollment/install command using only a CA URL plus optional admission and host overrides. It selects the designated key, completes enrollment, installs the SSH CA and offline AuthorizedPrincipalsCommand configuration, validates with sshd -t, reloads sshd, and writes active state atomically. Acceptance: installation is idempotent and rollback-safe; missing state is safely unenrolled; corrupt state or key mismatch is a hard error; no persistent host agent or correctness-critical scheduler is installed.
