Implement one default-closed enrollment state machine for manual windows,
scoped tokens, and pluggable machine attestations. A generated per-host domain
is non-secret and never serves as proof of possession; enrollment
authentication and admission authorize the host record and its requested
principal-domain membership. Acceptance: authentication precedes admission;
manual requests allocate state only in a bounded TTL/count window; pending
entries are size-limited, deduplicated, expiring, and rate-limited; tokens are
short-lived, scoped, single-use by default, hashed at rest, and atomically
bound to one enrollment request, host record, and allowed named or generated
domain; every approval records its actor.
