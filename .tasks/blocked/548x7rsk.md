Keep `--ca-url` as the only bootstrap input. On GET of the CA URL, continue serving the SSH CA public key and conditionally add one or more host-enrollment links using a distinct Link relation only when managed dynamic inventory is configured; Epithet Simple/static deployments omit that relation. Model enrollment targets as a list from the outset so redundant service URLs do not require a protocol change; endpoint ordering, selection, and failover policy are deferred. Advertisement reflects configured capability, not backend health: a managed deployment continues advertising the relation during an outage so enrollment fails visibly instead of silently falling back to an unregistered static result. The enrollment targets may direct authenticated control traffic to managed services rather than making the CA a control-plane proxy. Define typed discovery and an endpoint-agent token operation with one forced-refresh retry, then use the short-lived OIDC identity for administrative CLI calls. Acceptance: absence of the enrollment relation unambiguously selects local/static enrollment; refresh tokens never leave the broker; enrollment approver, host administrator, policy administrator, and audit reader are separate audited control-plane roles outside Writ.
