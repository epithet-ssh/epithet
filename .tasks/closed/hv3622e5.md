Resolved by explicit user decision during API audit follow-up.

client_secret is intentionally distributed through public login discovery when configured. It cannot be treated as confidential once given to installed clients. The user confirmed that Google requires clients to present this value and documents that it is not actually secret in this client context, despite the field name.

Preserve inventory configuration, inventory-to-CA discovery, and CA-to-agent publication of the configured value. Do not remove it or classify its intentional publication as an internal-diagnostic leak. This is part of the supported login contract, distinct from accidental exposure of backend URLs, raw service errors, or private audit metadata.

Closing the exploration as resolved: no implementation change is required. A future proposal to change supported OAuth client types would need its own compatibility justification.
