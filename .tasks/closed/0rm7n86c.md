Replace SSH-key-derived principal identity with an immutable, non-secret host ID. Define the canonical `epithet-host-v1-<base64url-no-padding of 32 random bytes)>` representation; make principal derivation hash the validated token byte-for-byte; replace static inventory `identity-key` with `host-id`; update the offline AuthorizedPrincipalsCommand helper to read exactly one host-ID file; and preserve destination-isolation coverage against live OpenSSH. Acceptance: the on-host file and static inventory use the exact same token; malformed or missing IDs fail closed; changing an SSH transport key does not change principals; changing a host ID means enrolling a new host, never in-place rotation.
