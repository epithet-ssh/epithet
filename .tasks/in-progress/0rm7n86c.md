Implement the privileged, one-shot local `epithet host enroll --ca-url <url>` foundation; the CA URL is the only required bootstrap input. A GET of that URL supplies the SSH CA public key. Enrollment generates and durably stores a host ID as one canonical text line, `epithet-host-v1-<base64url-no-padding of 32 random bytes)>`; the on-host file and static inventory use exactly the same token, and principal derivation consumes that validated token byte-for-byte. Enrollment then installs the SSH CA public key and offline AuthorizedPrincipalsCommand configuration, validates the resulting configuration with `sshd -t`, and reloads sshd. The host-ID location defaults from an explicit `runtime.GOOS` mapping and may be overridden at enrollment time. Enrollment resolves it to an absolute path and writes that actual path into the installed AuthorizedPrincipalsCommand, so authorization does not repeat platform discovery or require the override. Re-enrollment preserves the recorded path; selecting a different path is an explicit relocation operation and must not create a second identity accidentally. Static inventory and bespoke policy servers receive the host ID in command output for out-of-band registration. Acceptance: local enrollment works without managed inventory; it is idempotent and rollback-safe; it never silently replaces an existing host ID; missing state is safely unenrolled; malformed state is a hard error; partial failure does not leave sshd misconfigured; no persistent host agent or correctness-critical scheduler is installed.
